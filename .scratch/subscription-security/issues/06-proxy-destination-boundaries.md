# 06 验证并限制代理目标范围

Status: open
Scope: planned
Priority: must-minimum
Blocked by: none

## 问题

仅靠静态入口路由不能证明持有有效代理凭据的人无法访问出口侧私网、管理服务或云元数据；当前可达性未知。

## 必须的基础核查

- [ ] 在一次性隔离 Linux 环境建立与现有入口、VPN 和出口相符的拓扑，验证环回、链路本地、私网、云元数据模拟地址和管理端口的可达性；记录实际行为及覆盖缺口。
- [ ] 根据验证结果决定是否需要最小目标限制；如需实施，考虑域名与解析后 IP、DNS 重绑定、IPv4/IPv6、映射地址、重定向及直连 IP，明确保护失效或解析失败时的行为。
- [ ] 明确必要的 VPN、DNS 和承载基础设施例外，验证正常国外业务与国内直连规则、VPN-over-proxy 和 fail-closed 不被破坏。
- [ ] 禁止为了证明风险而探测真实生产内网或云元数据；如需防护变更，提供迁移和回滚方案，生产应用需另行授权。

## 暂缓

通用目标策略平台和未经风险证据支持的大范围限制暂不建设。隔离故障/网络实验是否执行依用户届时指令，不能由本待办推定授权。

## Comments

2026-10-26：这是待验证的风险，不声明当前已有私网或元数据可达漏洞。
