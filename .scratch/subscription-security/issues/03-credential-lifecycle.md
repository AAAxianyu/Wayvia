# 03 泄露处置与凭据生命周期

Status: not-current-issue
Scope: historical-planning
Priority: not-current
Blocked by: none

## 问题

订阅链接相当于可下载该设备代理密码的凭证。只撤销链接或让链接过期不会撤销已导出的密码；同设备多个链接共享凭据。

用户确认不将此项列为当前待处理问题；已有撤销及轮换能力保留，以下原计划不自动执行。
