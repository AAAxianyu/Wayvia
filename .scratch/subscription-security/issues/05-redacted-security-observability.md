# 05 脱敏安全观测与告警

Status: implemented_software_verified
Scope: repository_only_production_pending
Priority: must-minimum
Blocked by: none

## 问题

订阅站点不保存访问/错误日志，减少凭证泄露面，但也难以判断异常下载、无效令牌请求和限流触发情况。

## 必须的最小范围

- [x] 利用现有能力或最小增量，提供有界的服务状态、请求结果与统计缺失信息；01 落地后能查看限流次数。定义所需容量、权限和保留期限，已由后续授权的独立日志系统承接。
- [x] 仅使用受控、不可逆的关联标识；不记录完整 URL、令牌、代理密码、原始请求头、业务内容或可能反推凭据的原始值。对跨源关联明确隐私和密钥管理。
- [x] 区分无异常、无数据、记录失败和被限流；不要求新后台任务或通知渠道。
- [ ] 注入合成恶意 URL、异常头、日志写入失败、容量耗尽和重启等案例，检查输出及导出均不泄露秘密，且观测失败不取消限流。

## 暂缓

跨源关联、复杂告警投递、长期采集与报表仅在实际维护需求明确后评估；原有代码和数据保留。
