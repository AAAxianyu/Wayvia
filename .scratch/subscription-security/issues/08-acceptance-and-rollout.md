## TODO 与验收

- [ ] 针对每次实际变更，选取适用的跨设备、链接、撤销与轮换、缓存失效、速率/并发限制、脱敏或目标边界检查；暂缓功能不作为该次交付前置条件，注明不能验证的能力。
- [ ] 执行并记录仓库门禁 `make check`、`make demo`、`make test-configs`、`make test-lab`；环境缺失显式非零，用户暂缓的项目标明未运行，不冒充通过。
- [ ] 使用锁定组件和合成数据验证大配置与真实客户端核心兼容、资源开销、错误响应及并发恢复，记录版本、方法和证据。更新 `compatibility.yaml`、`docs/implementation-status.md`、`docs/validation/`。
- [ ] 准备部署前备份、保留现有设备/订阅和历史数据、限流参数、维护中断范围、验证与回滚步骤；敏感信息不得进入证据。
- [ ] 单列线上授权及验收清单。生产部署、真实采样、故障/重启测试和通知启用按用户届时指令执行，不把软件或隔离结果当作线上验收。
