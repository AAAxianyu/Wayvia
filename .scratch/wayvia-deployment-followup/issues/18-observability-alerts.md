# 18 可操作告警与观测完整性

Status: open
Priority: P2

## 缺口

曾依靠临时聊天 heartbeat 人工复核故障、采样停止和本地 ENOSPC；这不等于产品内已有可靠的告警与证据完整性检查。

## TODO 与验收

- [ ] 记录新增 DEGRADED、恢复、证据过期、采样意外停止、磁盘不足及轮转失败，区分用户主动停止和按期完成。
- [ ] 同一故障去重合并，正常状态安静；提供当前状态、发生时间、证据链接、缺失范围及需要操作的事项。
- [ ] 监测两端时间偏差、样本覆盖率和日志空洞；采集器失联不能直接被归类为业务断连。
- [ ] 通知渠道必须显式配置并授权；告警本身不自动重启、改路由或恢复已结束的观察。
