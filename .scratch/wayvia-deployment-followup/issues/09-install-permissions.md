# 09 复核严格 umask 下的安装与重装权限

Status: open
Priority: P2

## 当前证据

部署辅助脚本在 umask 077 下强制重装 Python 包后，wayvia 服务账户无法读取包/入口；已仅修复非秘密包与入口权限并恢复。尚未形成正式安装器针对该路径的长期回归。

## 前置条件

允许本地静态审查；实际安装复现仅在一次性 Linux 环境，包含恢复测试时遵循暂缓要求。

## 下一步

区分正式安装器与外部 uv 重装辅助脚本的责任，审查包落盘权限、服务账户可读性和失败后恢复。隔离复现严格 umask，必要时在拥有权边界内修正；禁止宽泛 chmod /etc 或秘密目录。

## 完成标准

记录可复现条件和责任归属，修正或文档约束覆盖重复安装，服务可正常启动，私钥/令牌权限保持最小化。
