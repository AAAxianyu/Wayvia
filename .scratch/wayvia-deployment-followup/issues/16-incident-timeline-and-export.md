# 16 统一故障时间线与脱敏证据导出

Status: open
Priority: P2

## 缺口

现有 journal、事务状态、设备审计和临时诊断分散，调查依赖手工选窗口与关联。当前还不能一键交付具备版本、覆盖率和归因边界的故障证据。

## TODO 与验收

- [ ] 为自然故障生成事件标识，串联两端请求失败、保护动作、服务停启及恢复；关联实际部署版本、配置 revision/generation 和维护标记。
- [ ] 保存 UTC 与显式时区，支持按设备、时间、层级查询；终端身份和版本注明用户确认/实际采集来源，不能仅靠相同订阅名称认定物理设备。
- [ ] 提供只读、字段白名单的诊断导出，含日志覆盖率、缺失窗口和完整性校验；证据不完整时保留 unknown。
- [ ] 区分管理 SSH 失败、探针刻意结束的短连接、真实业务失败和维护重启；不将所有 TLS/reset 日志计成用户断连。
- [ ] 导出不包含凭据、完整订阅、业务响应、原始计划或未授权终端日志；明确访问权限及保留期限。
