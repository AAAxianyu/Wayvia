# 03 管理入口与凭据安全

Status: open
Scope: planned
Priority: must
Blocked by: none

## TODO 与验收

- [ ] 检查现有管理员登录、密钥保存、账号权限和恢复入口；验证管理 API 不从公开订阅入口访问。引用安全 07 的接口检查，避免重复改造。
- [ ] 制定服务器凭据轮换及泄露应对步骤。涉及登录方式或停用密码认证前，先验证可用的替代管理入口和回退方案，避免锁住管理员。
- [ ] 检查订阅 URL、代理密码、私钥不进入公开日志和文档；设备信息和安全事件按最小必要保留。
- [ ] 使用合成配置和隔离环境验证必要变更；不擅自改生产 SSH、全局防火墙或其他服务。

## Comments

2026-10-26：该任务为规划，不授权立即修改现有登录方式或轮换生产凭据。
