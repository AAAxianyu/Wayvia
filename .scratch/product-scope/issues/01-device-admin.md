# 01 管理员日常设备管理

Status: open
Scope: planned
Priority: must
Blocked by: none

## TODO 与验收

- [ ] 整理管理员使用现有能力添加、查看、撤销、轮换设备和为其签发/重发订阅的最短流程；家庭成员只需导入，避免要求其理解服务器或注册账号。
- [ ] 明确设备、订阅和代理密码的关系：一设备一凭据、同设备多链接共享凭据；单独撤销链接不撤销已导出的密码，轮换会影响全部既有入口连接。
- [ ] 如现有 CLI 无法完成上述流程，先明确缺口和兼容性，再做最小改进；不默认建设公开自助管理页面。
- [ ] 使用合成设备验证新增、查看、撤销、轮换、失效/重新发放及不影响其他设备凭据；证明失败、重试与日志不会泄露秘密。
