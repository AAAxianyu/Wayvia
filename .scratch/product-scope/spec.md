# Wayvia 私人使用产品范围

Status: accepted
Date: 2026-10-26 America/Los_Angeles

Wayvia 供管理员本人及少量家人朋友使用。管理员统一维护设备、订阅、服务器与排障；其他使用者只需导入并使用管理员提供的链接，无需注册或自助管理。产品优先保证连接稳定、安全和维护简单，同时提供基础防滥用与设备管理。对外表述见 [产品介绍](../../docs/product-overview.md)，执行范围见 [TODO](TODO.md)。

## 已确定的边界

- 必须保留国内及本地资源直连、VPN-over-proxy、服务器侧承载秘密、受保护流量 fail-closed 和设备凭据隔离。客户端停止、网络切换、DNS 和 IPv6 的实际行为以对应平台验证为准。
- 每台设备应有独立凭据；链接与导出配置均属秘密。单独撤销订阅只停止未来下载，设备轮换/撤销才影响已导出的设备密码；当前凭据同步会中断既有入口会话。
- 设备管理属于管理员操作；流量数据是尽力统计的代理负载，不包括国内直连，也不是精确账单。缺测不等于零或离线。
- 一个有效设备仍可占用共享代理带宽；入口限流只保护订阅端点，不是按设备限速，也不能保证多人观看高清视频流畅。当前已知入口带宽上限为 3 Mbps，容量随部署变化，不能作为永久规格。
- 可复用既有诊断、历史和告警软件；不默认开启长期诊断、采样、通知或高级自动恢复。故障时间线和诊断代码的既有软件交付不等于实际生产验收。
- 用户自助注册、售卖支付、套餐账单、精确应用/网站历史、复杂多租户平台和虚构多线路不在产品范围。OpenWrt 接入暂缓且未完成，不作为现有能力。

## 授权和验收

本次只更新产品定义及规划，不授权实现、部署、改配置、轮换凭据或开展生产采样/故障测试。按用户此前约束，实网采样及故障测试暂缓；后续操作依用户届时指令。隔离环境的故障实验同样不因本规划自动获准。

每项开发按 AGENTS.md 的软件与隔离环境门禁记录验证，环境缺失明确非零；暂缓的测试标记未运行及原因。保护原数据，区分软件、隔离路径和生产接受度。原有安全、稳定性和客户端适配记录保留为历史；需求优先级以本文件和 [TODO](TODO.md) 为准。
