# Wayvia 途序

智能分流代理网关。国内服务直连，海外服务按需代理，手机、电脑与支持的路由器共用自有出口。

## 连接路径

- 国内与本地资源：通过终端当前网络直连。
- 海外服务：通过阿里云入口接入，经代理承载的 OpenVPN 链路连接自有日本出口。

日本服务器同时运行代理服务端与 OpenVPN 服务端，终端使用兼容客户端或支持的路由器接入。
