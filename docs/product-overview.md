# Wayvia 途序产品介绍

国内服务直连，海外服务按需代理，手机和电脑共用自有出口。

## 产品概述

Wayvia 途序是一套供自己和少量家人朋友使用的私人分流代理服务。它根据访问目标选择连接路径：国内服务沿当前网络直接访问，需要代理的海外服务通过统一入口连接到自有海外出口。

使用者在兼容客户端中导入管理员提供的私人订阅，即可按规则使用代理。管理员统一负责设备、订阅、服务器、更新和排障；使用者不需要注册账号或管理服务器。节点、分流和 DNS 策略由同一配置来源维护，并按不同设备生成适配格式。

产品首先重视稳定连接、安全和方便维护，同时提供基本防滥用与设备管理。它不以公开售卖、大量用户自助服务或计费为目标。当前产品优先级与未完成事项见 [产品范围 TODO](../.scratch/product-scope/TODO.md)；原有设计和已完成的软件能力作为历史与实现依据保留。

## 核心功能

### 智能分流

国内网站和本地资源使用当前网络直连，海外服务按规则使用代理。将流量分配到各自的访问路径，减少国内业务绕行，并保留局域网设备和内部资源的访问方式。

分流规则支持维护和更新。出现域名归属、CDN 或应用访问路径变化时，可通过明确规则修正。

### 统一代理接入

手机和电脑连接统一入口，由服务器维护后续出口链路。用户无需在终端分别管理服务器之间的代理连接和 VPN 证书。

配置可随设备在 Wi-Fi 与蜂窝网络上使用。切换网络时由客户端重新建立连接，具体恢复表现取决于网络及客户端。

### 自有海外出口

服务通过自有日本节点提供统一的海外出口，供多个终端共用。部署者集中管理节点配置、访问凭据和出口地址。

海外出口同时运行代理和 VPN 服务。代理承载服务器之间的 VPN 连接，VPN 提供统一的出站路径；各段连接使用加密传输。

### 多端配置分发

为 Android、iPhone 及兼容电脑客户端提供适配配置。节点信息、分流规则和 DNS 设置一起交付，通过私人订阅统一更新。

设备使用独立凭据，便于撤销或轮换访问权限。客户端需支持配置中使用的接入协议、分流规则与网络接管功能。

### 路由器接入（暂缓）

OpenWrt 网关可作为后续扩展，为不便安装客户端的设备提供分流；当前尚未实现或验收，不作为现阶段必需功能。

### 明确的连接状态与故障行为

分别检查入口、代理、VPN 和最终业务的连接状态，帮助判断故障发生在哪一段。

代理链路不可用时，已被客户端接管并指定走代理的请求停止；国内直连继续使用当前网络。DNS 和 IPv6 策略与分流规则一起配置和验证。

## 连接如何工作

```text
手机 / 电脑
    │
    ├─ 国内服务与本地资源 → 当前网络直连
    │
    └─ 需要代理的海外服务
            → 国内接入网关
            → 由代理承载的 VPN 连接
            → 自有海外出口
            → 目标服务
```

终端负责选择直连或代理，服务器负责接入和出口。国内服务器提供统一入口，海外服务器同时运行代理和 VPN 服务，共同组成完整的代理链路。

## 使用方式

1. **获取设备配置**：由管理员为设备提供对应的私人订阅或配置。
2. **导入并启用**：开启客户端所需的网络接管功能，验证入口连接。
3. **按规则访问**：国内服务直连，海外服务自动使用代理。
4. **需要帮助时联系管理员**：由管理员处理设备变更、链接失效和连接问题。

日常使用中，用户主要关注配置是否有效和连接是否正常。服务器间的双层连接由部署者维护。

## 适用场景

| 场景 | 主要价值 |
| --- | --- |
| 同时使用国内网站与海外 SaaS | 按目标分流，国内业务保持本地直连 |
| 访问开发文档、代码仓库和远程工具 | 通过统一代理入口使用自有海外出口 |
| 手机、电脑等多个终端接入 | 集中维护节点与规则，按客户端分发配置 |
| 自己与少量家人朋友共享 | 管理员统一管理服务器、设备凭据与出口 |

## 使用条件

终端需使用兼容客户端并启用相应的网络接管功能。分流、DNS 与 IPv6 设置随完整配置一同启用；各平台实际接管效果仍以对应验收为准。

连接速度、并发容量和重连表现取决于终端网络、服务器资源、传输线路及目标服务。使用蜂窝网络会正常消耗流量套餐。

节点由部署者运维，凭据、更新和日志策略也由部署者管理。服务采用加密传输，代理运营端仍可能接触连接目标等元数据；应用自身的 HTTPS 证书校验应保持开启。

## 简短介绍

Wayvia 途序是一套供自己和少量家人朋友使用的私人代理服务。国内服务通过当前网络直连，需要代理的海外服务经统一入口使用自有海外出口。管理员集中维护设备、订阅和服务器，使用者在手机或电脑导入自己的配置即可使用。

## 私有日志与管理员平台

管理员可在独立私有入口查询设备用量及可观测连接目标、订阅请求和限流原因、两端服务事件、管理操作与采集缺口。家人朋友继续使用现有链接，不增加注册、证书安装或客户端操作。日志只保存有期限的连接元数据，不读取 HTTPS 正文、完整网页路径或具体消息。

该功能已完成仓库开发和软件验证，尚未部署或启用生产采集。平台通过回环端口与 SSH 隧道访问，默认共享导出脱敏；见[使用与运维](logging-admin.md)和[验收范围](validation/logging-admin-2026-10-27/README.md)。
