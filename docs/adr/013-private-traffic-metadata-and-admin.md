# ADR 013：私有连接元数据日志与管理员平台

日期：2026-10-27。状态：接受，仓库实现；生产启用另行验收。

Wayvia 由一个管理员供自己与少量家人朋友使用。使用者继续只导入原订阅，排障、设备与防滥用由管理员负责。增加被动日志和私有管理界面，不改变原订阅 URL、令牌、设备密码、发布配置、DNS、分流或恢复决策。

## 决定

1. 新增独立 `observability.db`，保存可观测的来源/目标 IP、核心提供的域名、端口、凭据归属、连接起止与字节、入口限流、白名单系统/SSH 事件。此决定仅替代 ADR 007/010 对**新日志库**不保存来源/目标的限制。原 usage adapter、累计量、历史桶、evidence v1、有限 diagnostics run 与 ZIP 导出契约保持。
2. 不截获正文、不保存完整 URI/查询串/请求头、不安装中间人证书，不把连接解释成人的操作、网页路径、视频名称或消息内容。国内直连、端到端 HTTPS 内容不可由此观测。
3. Nginx 只输出固定字段到本机 Unix datagram；API 认证成功后补身份。用可信代理生成的请求 ID 合并一条请求。速率和并发拒绝来自各自 Nginx 变量，只有 HTTP 429 时标为原因未知。失败请求不根据猜测的 token 关联设备。
4. sing-box 1.14.3/API 4 的独立长期流读取器运行在自己的进程，不进入原串行 root agent。设备凭据、核心 epoch 和连接 ID 共同界定归属。重放、断流、缺起止、超期活动连接及计数重置显式处理；明细不重复加到旧累计值。
5. 日志策略持久化且初始关闭。停用不停止代理、不恢复旧诊断、不自动发通知。进程重启只遵从该策略。日志失败旁路降级；新的管理员写操作须先留下持久审计。
6. 管理界面只监听回环端口，通过 SSH 隧道使用。一次性码 60 秒，会话空闲 30 分钟、最长 8 小时，数据库只存哈希；HttpOnly/SameSite、Host/Origin、CSRF、CSP 与有限动作共同保护。浏览器不持有控制 API bearer。
7. 新进程资源归入独立 systemd slice。独立账户、内核 Unix peer credentials 和固定查询 broker 隔离日志、控制秘密与根权限。对端只传投影后的有界批次，强制 SSH 命令、主机密钥校验、摘要/序号/确认和有限 spool；不提供任意 shell/路径/SQL。
8. 默认连接 7 天、请求/SSH 14 天、系统 30 天、管理 90 天，明细查询最多 24 小时/500 条。请求日汇总不带目标保留 90 天。默认共享导出每包使用新的不可逆代号，内部明细需单独确认；导出绑定创建会话、24 小时过期。

## 可知与不可知

原生连接流与 syslog 都不是可证明无损的账本。查询数量始终是已记录数量，空结果、静默来源、重启、排队丢弃、时钟问题与保留范围必须独立展示。旧流量统计仍是已有的尽力而为代理 payload 统计。共享凭据不能识别物理设备，同一设备的多个链接不能拆成各链接的业务用量。

日志部署不会自动重载核心或改网络。软件、禁外网容器正常路径和真实部署分别验收；故障注入与完整网络实验沿用既有暂缓约束。
