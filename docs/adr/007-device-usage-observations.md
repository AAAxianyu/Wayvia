# ADR-007: Per-device usage through the authenticated local core API

Date: 2026-10-21. Status: accepted for the locked sing-box 1.14.3 / native API 4.

Devices already have independent Trojan credentials. Subscription revocation only denies future downloads; device revocation closes ingress sessions and removes the credential from the durable recovery snapshot. To retire shared configurations, revoke both the old subscriptions and their shared device account. Preserve the audit rows.

The root ingress executor adds one native API service at **127.0.0.1:19090**, authenticated by a generated root-only secret. No dashboard, CORS expansion, external listener, or proxy publication is permitted. The fixed agent operation `device_usage` accepts no URL, method or credential arguments. It calls only GetVersion, GetStartedAt and the initial SubscribeConnections snapshot, then cancels that stream. The adapter requires the locked version and API revision, limits deadlines and message size, rejects inconsistent generations, and returns only device/connection identifiers, times and byte counters. Source/target addresses, domains, payloads and API secrets do not leave the root adapter. The internal probe account is excluded.

The five-second `wayvia-usage` collector runs as the service user, with AF_UNIX only, and persists data in the existing private SQLite store. An active authenticated proxy connection is **online**; this is not physical device reachability or proof that the client application is running. Observations older than 20 seconds or a failed collection report **unknown**, not offline. `last_used_at` is the latest observed transfer or newly observed connection, not subscription download time. Counts belong to credentials; sharing one link on multiple physical devices defeats that distinction.

Upload/download mean proxied payload bytes measured by the ingress core, including application headers but excluding domestic direct traffic and carrier/TLS/VPN overhead. Per-connection cumulative high-water marks prevent double counting, including short connections retained in the core's closed-connection ring. Totals persist across collector/core restarts. Core generation changes, lost final counters and a full closed ring newer than the last successful sample mark a coverage gap. Abrupt termination can lose unsampled bytes, and the ring retains only the latest 1,000 closed connections. These are best-effort operational totals, **not billing-grade or retroactive usage**. No claim of exact delivery to the final website is made.

Rejected alternatives: source-IP attribution conflates NAT users; sing-box's Clash connection API omits the authenticated user; subscription fetch timestamps measure configuration retrieval rather than proxy use. One port per user would unnecessarily change the client/network topology. Native API snapshot projection keeps all existing routing and transport order intact.
